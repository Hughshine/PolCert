Which compile endpoint?

The repeated names encode three independent choices. A module beginning with S is the concrete, extraction-facing implementation; the theorem for it lives in ExtractedPipelineCorrect. VerifiedCompilerConfig is the sequential Loop -> Loop dispatcher, while VerifiedParallelCompilerConfig is the unified Loop -> ParallelLoop dispatcher. Finally, compile_verified starts after the outer configuration check; compile accepts raw_config and performs that check. Route-specific program validators still run in both cases.

Deep-reading tracks

Extraction

Frontend owns the executable translation, Facts owns slices and partitions, and Correct owns semantic reconstruction. The facade is intentionally omitted.

Tiling

Read representation correspondence before the band validator. In the latter, skip the explicitly marked legacy affine-reduction subsection on a first pass.

Parallel code generation

Core defines tag/erase and source-origin primitives; Compatibility contains legacy wrappers plus the live slice/origin support interface; Correct consumes certificates along the actual trace and proves the checked endpoints.
