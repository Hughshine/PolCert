What This Case Checks

Checks the direct permutable-band tiling route and its output, alarm, and fallback behavior.

Expected outcome
The permutable-band validator must emit an optimized output, with no fallback or rejection alarm.
Recorded outcome
Direct-only route contract matched.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
The route boundary prevents malformed or inapplicable tiling proposals from reaching code generation.

Before Program

context(N);

for i in range(0, N) {
  for j in range(0, N) {
    C[i][j] = 0;

      C[i][j] = (C[i][j] + (A[i][k] * B[k][j]));
    }
  }
}

Accepted Program

context(N);

if (1 <= N) {
  for i0 in range(0, ((N + 31) / 32)) {
    for i1 in range(0, ((N + 31) / 32)) {
      for i2 in range(max(0, (32 * i0)), min(N, ((32 * i0) + 32))) {
        for i3 in range(max(0, (32 * i1)), min(N, ((32 * i1) + 32))) {
          C[i2][i3] = 0;
        }
      }
    }
  }
}
if (1 <= N) {
  for i0 in range(0, ((N + 31) / 32)) {
    for i1 in range(0, ((N + 31) / 32)) {
      for i2 in range(0, ((N + 31) / 32)) {
        for i3 in range(max((32 * i0), 0), min(((32 * i0) + 32), N)) {
          for i4 in range(max((32 * i1), 0), min(((32 * i1) + 32), N)) {
            for i5 in range(max((32 * i2), 0), min(((32 * i2) + 32), N)) {
              C[i3][i4] = (C[i3][i4] + (A[i3][i5] * B[i5][i4]));
            }
          }
        }
      }
    }
  }
}
