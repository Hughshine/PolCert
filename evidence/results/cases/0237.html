What This Case Checks

Exercises one-level tiling and its optional consumer on this route configuration.

Expected outcome
The route must accept this configuration through the direct permutable-band validator.
Recorded outcome
One-level route composition matched.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
The route must accept only a certified tiling shape and must not attach an uncertified loop annotation.

Before Program

context(N, M);

for i in range(0, N) {
  for j in range(0, M) {
    A[i][j] = (B[i][j] + 1);
  }
}

Accepted Program

context(N, M);

if ((1 <= N && 1 <= M)) {
  for i0 in range(0, ((N + 31) / 32)) {
    for i1 in range(0, ((M + 31) / 32)) {
      for i2 in range(max(0, (32 * i0)), min(N, ((32 * i0) + 32))) {
        vector for i3 in range(max(0, (32 * i1)), min(M, ((32 * i1) + 32))) {
          A[i2][i3] = (B[i2][i3] + 1);
        }
      }
    }
  }
}

Dynamic Execution
