Ordinary tiling; Parallelization

What This Case Checks

Checks whether the selected schedule dimension can be represented as a verified parallel loop.

Expected outcome
The validator must accept the requested transformation and expose the declared structural markers.
Recorded outcome
Requested result and effects observed.
Why this test matters
Parallel iterations may interleave, so a dependence-carrying or nonexistent dimension must be rejected.

Before Program

context(N);

for i in range(0, N) {
  for j in range(0, N) {
    C[i][j] = 0;
    for k in range(0, N) {
      C[i][j] = (C[i][j] + (A[i][k] * B[k][j]));
    }
  }
}

Accepted Program

context(N);

if (1 <= N) {
  for i0 in range(0, ((N + 31) / 32)) {
    parallel for i1 in range(0, ((N + 31) / 32)) {
      for i2 in range(max(0, (32 * i0)), min(N, ((32 * i0) + 32))) {
        for i3 in range(max(0, (32 * i1)), min(N, ((32 * i1) + 32))) {
          C[i2][i3] = 0;
        }
      }
      for i2 in range(0, ((N + 31) / 32)) {
        for i3 in range(max(0, (32 * i0)), min(N, ((32 * i0) + 32))) {
          for i4 in range(max(0, (32 * i1)), min(N, ((32 * i1) + 32))) {
            for i5 in range(max((32 * i2), 0), min(((32 * i2) + 32), N)) {
              C[i3][i4] = (C[i3][i4] + (A[i3][i5] * B[i5][i4]));
            }
          }
        }
      }
    }
  }
}
