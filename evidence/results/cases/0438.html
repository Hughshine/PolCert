diamond-iss-current-combined-effect

Index-set splitting (ISS); Diamond tiling; Parallelization

What This Case Checks

Checks whether the selected schedule dimension can be represented as a verified parallel loop.

Expected outcome
The validator must accept the requested transformation and expose the declared structural markers.
Recorded outcome
Requested result and effects observed.
Why this test matters
Parallel iterations may interleave, so a dependence-carrying or nonexistent dimension must be rejected.

Before Program

context(B, T, N);

for t in range(5, (T - 1)) {
  for i in range(5, (N - 5)) {
    for p in range(0, B) {
      A[p][(t + 1)][i] = (0.125 * (A[p][t][(i - 1)] + A[p][(t - 2)][(i + 1)]));
    }
  }
}

Accepted Program

context(B, T, N);

if ((1 <= B && (7 <= T && 11 <= N))) {
  parallel for i0 in range(0, ((B + 31) / 32)) {
    for i1 in range(0, ((T + (N + 24)) / 32)) {
      for i2 in range(max(0, (((-1 * N) + ((32 * i1) + 6)) / 32)), min(((T + 30) / 32), (((32 * i1) + 58) / 32))) {
        for i3 in range(max((32 * i0), 0), min(((32 * i0) + 32), B)) {
          for i4 in range(max(max(10, ((32 * i2) + 5)), (32 * i1)), min(min((T + (N + -7)), (N + ((32 * i2) + 26))), ((32 * i1) + 32))) {
            for i5 in range(max(max((32 * i2), 5), ((-1 * N) + (i4 + 6))), min(min(((32 * i2) + 32), (T + -1)), (i4 + -4))) {
              for i6 in range((i4 + (-1 * i5)), (i4 + ((-1 * i5) + 1))) {
                A[i3][(i5 + 1)][i6] = (0.125 * (A[i3][i5][(i6 + -1)] + A[i3][(i5 + -2)][(i6 + 1)]));
              }
            }
          }
        }
      }
    }
  }
}
