native-const-unroll-inside-parallel-hint

Parallelization; Constant-bound loop unrolling

What This Case Checks

Exercises one Pluto-compatible driver option combination and its declared route or effect contract.

Expected outcome
The driver must accept the request and satisfy 2 effect contracts.
Recorded outcome
Route and optimization contract matched.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
The wrapper must reject contradictory or unsupported requests and route accepted requests without silently dropping required effects.

Before Program

for i in range(0, 100) {
  for j in range(0, 4) {
    A[((4 * i) + j)] = ((2 * A[((4 * i) + j)]) + 2);
  }
}

Accepted Program

parallel for i0 in range(0, 100) {
  A[(4 * i0)] = ((2 * A[(4 * i0)]) + 2);
  A[((4 * i0) + 1)] = ((2 * A[((4 * i0) + 1)]) + 2);
  A[((4 * i0) + 2)] = ((2 * A[((4 * i0) + 2)]) + 2);
  A[((4 * i0) + 3)] = ((2 * A[((4 * i0) + 3)]) + 2);
}

Dynamic Execution
