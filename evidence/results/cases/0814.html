What This Case Checks

Checks how identity affine scheduling composes with a later tiling request.

Expected outcome
The recorded result must satisfy this contract: two-level tiling remains effective with identity affine scheduling.

Why this test matters
Identity scheduling should not bypass the certificates required by the selected tiling route.

Accepted Program

context(N, M);

if (1 <= N) {
  for i0 in range(0, ((N + 255) / 256)) {
    for i1 in range(max(0, (8 * i0)), min(((N + 31) / 32), ((8 * i0) + 8))) {
      for i2 in range(max((32 * i1), 0), min(((32 * i1) + 32), N)) {
        a[i2] = b[i2];
      }
    }
  }
}
if (1 <= M) {
  for i0 in range(0, ((M + 255) / 256)) {
    for i1 in range(max(0, (8 * i0)), min(((M + 31) / 32), ((8 * i0) + 8))) {
      for i2 in range(max((32 * i1), 0), min(((32 * i1) + 32), M)) {
        a[i2] = b[i2];
      }
    }
  }
}
