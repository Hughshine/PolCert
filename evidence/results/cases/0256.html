Two-level tiling

What This Case Checks

Checks the direct permutable-band tiling route and its output, alarm, and fallback behavior.

Expected outcome
The permutable-band validator must emit an optimized output, with no fallback or rejection alarm.
Recorded outcome
Direct-only route contract matched.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
The route boundary prevents malformed or inapplicable tiling proposals from reaching code generation.

Before Program

context(N);

for i in range(0, N) {
  for j in range(0, N) {
    C[i][j] = 0;
    for k in range(0, N) {
      C[i][j] = (C[i][j] + (A[i][k] * B[k][j]));
    }
  }
}
