Loop fusion

What This Case Checks

Executes the baseline and generated C programs on the same inputs and compares their outputs.

Expected outcome
Baseline and generated executions must produce the same output.
Recorded outcome
Baseline and optimized outputs matched. This case has no separate structural-effect assertion.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
Execution checks complement the proof build by detecting integration or extraction mistakes in concrete generated programs.

Source Loop Program

context(N);

for i0 in range(1, (N + -2)) {
  A[i0] = (0.33 * ((In[(i0 + -1)] + In[i0]) + In[(i0 + 1)]));
}
for i0 in range(2, (N + -3)) {
  Out[i0] = (0.33 * ((A[(i0 + -1)] + A[i0]) + A[(i0 + 1)]));
}

Accepted Optimized Loop Program

context(N);

for i0 in range(1, min(3, (N + -2))) {
  A[i0] = (0.33 * ((In[(i0 + -1)] + In[i0]) + In[(i0 + 1)]));
}
for i0 in range(3, (N + -2)) {
  A[i0] = (0.33 * ((In[(i0 + -1)] + In[i0]) + In[(i0 + 1)]));
  for i1 in range((i0 + -1), i0) {
    Out[i1] = (0.33 * ((A[(i1 + -1)] + A[i1]) + A[(i1 + 1)]));
  }
}
