sequential-iss-notile

ISS route accepted; no loop transformation asserted

What This Case Checks

Checks ISS through the affine-only route with the specialized tiling validator disabled.

Expected outcome
The driver must accept the request; this case declares no structural-effect assertion.
Recorded outcome
The route was accepted; this case asserted no specific structural effect.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
This is an acceptance-only routing test. It does not assert that the accepted Loop lacks tile-shaped structure.

Before Program

context(M, N, K);

for i in range(0, M) {
  for j in range(0, N) {
    for k in range(0, K) {
      C[i][j] = ((beta * C[i][j]) + ((alpha * A[i][k]) * B[k][j]));
    }
  }
}

Accepted Program

context(M, N, K);

if ((1 <= M && (1 <= N && 1 <= K))) {
  for i0 in range(0, ((K + 31) / 32)) {
    for i1 in range(0, ((N + 31) / 32)) {
      for i2 in range(0, ((M + 31) / 32)) {
        for i3 in range(max((32 * i0), 0), min(((32 * i0) + 32), K)) {
          for i4 in range(max((32 * i1), 0), min(((32 * i1) + 32), N)) {
            for i5 in range(max((32 * i2), 0), min(((32 * i2) + 32), M)) {
              C[i5][i4] = ((beta * C[i5][i4]) + ((alpha * A[i5][i3]) * B[i3][i4]));
            }
          }
        }
      }
    }
  }
}

Dynamic Execution

The two displayed Loop programs were lowered with Rocq Z.div/Z.mod control semantics, compiled, and run from the same deterministic state. The harness feeds every finite modeled scalar and array element into SHA-256 in a fixed order.
