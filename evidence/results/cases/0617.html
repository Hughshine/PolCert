two-level-tiling-matmul

Two-level tiling

What This Case Checks

Runs a representative verified pipeline over a typed C-like instruction program and records its Loop shape.

Expected outcome
The typed pipeline must complete and exhibit the structural effect named by this case.
Recorded outcome
Two-level validator accepted an additional tile hierarchy.
Why this test matters
The structural comparison makes the effect of the verified component visible without reducing instructions to an empty payload.

Typed Input Program

context(M, N, K);

for i0 in range(0, M) {
  for i1 in range(0, N) {
    for i2 in range(0, K) {
      C[i0][i1] = (C[i0][i1] + (A[i0][i2] * B[i2][i1]));
    }
  }
}

Accepted Verified Program

context(M, N, K);

if ((1 <= M && (1 <= N && 1 <= K))) {
  for i0 in range(0, ((K + 255) / 256)) {
    for i1 in range(0, ((N + 255) / 256)) {
      for i2 in range(0, ((M + 255) / 256)) {
        for i3 in range(max(0, (8 * i0)), min(((K + 31) / 32), ((8 * i0) + 8))) {
          for i4 in range(max(0, (8 * i1)), min(((N + 31) / 32), ((8 * i1) + 8))) {
            for i5 in range(max(0, (8 * i2)), min(((M + 31) / 32), ((8 * i2) + 8))) {
              for i6 in range(max(0, (32 * i3)), min(K, ((32 * i3) + 32))) {
                for i7 in range(max(0, (32 * i4)), min(N, ((32 * i4) + 32))) {
                  for i8 in range(max((32 * i5), 0), min(((32 * i5) + 32), M)) {
                    C[i8][i7] = (C[i8][i7] + (A[i8][i6] * B[i6][i7]));
                  }
                }
              }
            }
          }
        }
      }
    }
  }
}
