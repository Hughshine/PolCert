ISS sensitivity comparison

What This Case Checks

Compares identity-tiling output with and without ISS for this corpus input.

Expected outcome
The search must compare the two accepted Loop outputs. This page must not infer an individual result when the retained log gives only totals.
Recorded outcome
The retained log reports only the suite totals, so this input has no independent per-case outcome.
Verdict
This page reports membership in an aggregate search result, not a per-input pass or failure.
Why this test matters
The search records whether ISS changes the generated program under an otherwise fixed schedule.

This search compares two accepted outputs; it is not a source-to-target compilation count.

Dynamic Execution

The two displayed Loop programs were lowered with Rocq Z.div/Z.mod control semantics, compiled, and run from the same deterministic state. The harness feeds every finite modeled scalar and array element into SHA-256 in a fixed order.
