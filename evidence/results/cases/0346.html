Diamond tiling

What This Case Checks

Runs the diamond-tiling producer and classifies the resulting transformation or producer failure.

Expected outcome
The recorded result must satisfy this contract: effect:diamond,route:permutable-band,phase:true.
Recorded outcome
Diamond effect and three phase contract matched.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
The suite distinguishes a verified diamond proposal from inputs for which Pluto produces no usable proposal.

// TILE-PARALLEL: T(S1): (t+i, t-i)
// TILE-PARALLEL: After tiling:

#pragma scop
for (t = 5; t < T - 1; t++) {
  for (i = 5; i < N - 5; i++) {
    A[t + 1][i] = 0.125 * (A[t][i - 1] + A[t - 2][i + 1]);
  }
}
#pragma endscop
