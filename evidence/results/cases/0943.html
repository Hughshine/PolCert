matmul-parallel-hint

Parallelization

What This Case Checks

Replays unsafe optimizer proposals and a valid parallel-hint mapping case.

Expected outcome
The raw Pluto hint must map to the intended canonical schedule coordinate, and both strict and permissive routes must certify it.
Recorded outcome
Strict and permissive modes map the hint through schedule canonicalization and certify the intended loop.
Why this test matters
The route must reject uncertified effects while preserving and certifying a valid optimizer hint against the intended loop.

Input Loop Program

context(M, N, K);

for i in range(0, M) {
  for j in range(0, N) {
    for k in range(0, K) {
      C[i][j] = ((beta * C[i][j]) + ((alpha * A[i][k]) * B[k][j]));
    }
  }
}

Strict validation stops before code generation, so this case has no target or rejected candidate program to display.

No before/after program run

This focused case checks hint-coordinate mapping and the selected parallel loop directly in the compiler output; it has no separate whole-C execution record.
