parallel-current-positive

Parallelization

What This Case Checks

Checks whether the selected schedule dimension can be represented as a verified parallel loop.

Expected outcome
The validator must accept the requested transformation and expose the declared structural markers.
Recorded outcome
Requested result and effects observed.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
Parallel iterations may interleave, so a dependence-carrying or nonexistent dimension must be rejected.

Before Program

for i in range(0, 100) {
  for j in range(0, 4) {
    A[((4 * i) + j)] = ((2 * A[((4 * i) + j)]) + 2);
  }
}

Accepted Program

parallel for i0 in range(0, 4) {
  for i1 in range(max(0, (32 * i0)), min(100, ((32 * i0) + 32))) {
    for i2 in range(0, 4) {
      A[((4 * i1) + i2)] = ((2 * A[((4 * i1) + i2)]) + 2);
    }
  }
}
