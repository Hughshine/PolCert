Intra-tile affine rescheduling

What This Case Checks

Checks output agreement and the requested intra-tile affine rescheduling effect.

Expected outcome
Baseline and generated executions must produce the same output.
Recorded outcome
The source and optimized programs produced the same result. The optimized program shows intra-tile affine rescheduling.
Why this test matters
This ensures the optional post-tiling schedule pass both runs and preserves the tested result.

Before Program

context(M, N, K);

for i in range(0, M) {
  for j in range(0, N) {
    for k in range(0, K) {
      C[i][j] = ((beta * C[i][j]) + ((alpha * A[i][k]) * B[k][j]));
    }
  }
}

Accepted Program

context(M, N, K);

if ((1 <= M && (1 <= N && 1 <= K))) {
  for i0 in range(0, ((M + 31) / 32)) {
    for i1 in range(0, ((N + 31) / 32)) {
      for i2 in range(0, ((K + 31) / 32)) {
        for i3 in range(max((32 * i0), 0), min(((32 * i0) + 32), M)) {
          for i4 in range(max(0, (32 * i2)), min(K, ((32 * i2) + 32))) {
            for i5 in range(max(0, (32 * i1)), min(N, ((32 * i1) + 32))) {
              C[i3][i5] = ((beta * C[i3][i5]) + ((alpha * A[i3][i4]) * B[i4][i5]));
            }
          }
        }
      }
    }
  }
}
