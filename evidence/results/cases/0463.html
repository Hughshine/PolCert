matmul-init

Block unrolling and validated loop jamming

What This Case Checks

Compares the input Loop program with the output of the checked unroll-and-jam postpass.

Expected outcome
The recorded result must satisfy this contract: native effect covered by checked PolOpt structure.
Recorded outcome
Checked-effect was observed.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
The test distinguishes proved block unrolling and local jamming from a producer option that has no checked structural effect.

Before Program

context(N);

for i in range(0, N) {
  for j in range(0, N) {
    C[i][j] = 0;
    for k in range(0, N) {
      C[i][j] = (C[i][j] + (A[i][k] * B[k][j]));
    }
  }
}

Accepted Program

context(N);

if (1 <= N) {
  for i0 in range(0, N) {
    for i1 in range(0, N) {
      C[i0][i1] = 0;
    }
  }
}
if (1 <= N) {
  if (1 <= N) {
    for i0 in range(0, (N / 4)) {
      for i1 in range(0, N) {
        for i2 in range(0, N) {
          C[(4 * i0)][i1] = (C[(4 * i0)][i1] + (A[(4 * i0)][i2] * B[i2][i1]));
          C[((4 * i0) + 1)][i1] = (C[((4 * i0) + 1)][i1] + (A[((4 * i0) + 1)][i2] * B[i2][i1]));
        }
        for i2 in range(0, N) {
          C[((4 * i0) + 2)][i1] = (C[((4 * i0) + 2)][i1] + (A[((4 * i0) + 2)][i2] * B[i2][i1]));
        }
        for i2 in range(0, N) {
          C[((4 * i0) + 3)][i1] = (C[((4 * i0) + 3)][i1] + (A[((4 * i0) + 3)][i2] * B[i2][i1]));
        }
      }
    }
    for i0 in range((4 * (N / 4)), N) {
      for i1 in range(0, N) {
        for i2 in range(0, N) {
          C[i0][i1] = (C[i0][i1] + (A[i0][i2] * B[i2][i1]));
        }
      }
    }
  }
}
