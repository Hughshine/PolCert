Index-set splitting (ISS)

What This Case Checks

Runs a representative verified pipeline over a typed C-like instruction program and records its Loop shape.

Expected outcome
The typed pipeline must complete and exhibit the structural effect named by this case.
Recorded outcome
ISS-validator-well-formedness-checker-and-codegen-all-accepted.
Verdict
PASS means the recorded behavior matched the expected result for this case.
Why this test matters
The structural comparison makes the effect of the verified component visible without reducing instructions to an empty payload.

Typed Input Program

context(RI_N);

for i0 in range(0, RI_N) {
  RI_A[i0] = (2 * RI_A[((RI_N - 1) - i0)]);
}

Accepted Verified Program

context(RI_N);

for i0 in range(0, ((RI_N + 1) / 2)) {
  RI_A[i0] = (2 * RI_A[((RI_N - 1) - i0)]);
}
for i0 in range(((RI_N + 1) / 2), RI_N) {
  RI_A[i0] = (2 * RI_A[((RI_N - 1) - i0)]);
}

Dynamic Execution

The two displayed Loop programs were lowered with Rocq Z.div/Z.mod control semantics, compiled, and run from the same deterministic state. The harness feeds every finite modeled scalar and array element into SHA-256 in a fixed order.
