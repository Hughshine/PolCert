Ordinary tiling

What This Case Checks

Runs a representative verified pipeline over a typed C-like instruction program and records its Loop shape.

Expected outcome
The typed pipeline must complete and exhibit the structural effect named by this case.
Recorded outcome
Validated band tiling added tile and point loops.
Why this test matters
The structural comparison makes the effect of the verified component visible without reducing instructions to an empty payload.

Typed Input Program

context(N, M);

for i0 in range(0, N) {
  for i1 in range(0, M) {
    A[i0][i1] = (B[i0][i1] + 1);
  }
}

Accepted Verified Program

context(N, M);

if ((1 <= N && 1 <= M)) {
  for i0 in range(0, ((N + 31) / 32)) {
    for i1 in range(0, ((M + 31) / 32)) {
      for i2 in range(max(0, (32 * i0)), min(N, ((32 * i0) + 32))) {
        for i3 in range(max(0, (32 * i1)), min(M, ((32 * i1) + 32))) {
          A[i2][i3] = (B[i2][i3] + 1);
        }
      }
    }
  }
}
