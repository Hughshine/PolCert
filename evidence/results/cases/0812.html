unrolljam-context-bound-escape-rejected

Block unrolling; context-escaping local jam rejected

What This Case Checks

Exercises one Pluto-compatible driver option combination and its declared route or effect contract.

Expected outcome
The route must retain checked block unrolling but omit the local jam whose body escapes its surrounding affine context.
Recorded outcome
The route retained its checked block-unroll effects and omitted the context-escaping local jam.
Verdict
PASS means the verified part was retained and the uncertifiable optional effect was not emitted.
Why this test matters
The wrapper must reject contradictory or unsupported requests and route accepted requests without silently dropping required effects.

Before Program

context(N, M, K);

for i in range(1, N) {
  for j in range(0, M) {
    A[i][j] = (A[(i + -1)][K] + 1);
  }
}

Why the Requested Effect Is Not Applied

Classification
Verified local fallback after an out-of-context jam
Reason
The proposed local jam would move a body whose access escapes the affine context used by the local certificate. PolCert keeps the checked block-unrolled structure and omits that jam.
